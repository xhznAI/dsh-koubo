# 准备人物形象

使用用户提供的照片或获准使用的人物图，按成片比例准备参考图，并保持人物、服装、光线与声音描述一致。可以用当前环境已配置的图片工具准备场景图，再通过 koubo_generate 的 imagePath 图生视频。

生图提示词写清人物、服装、背景与光线：单人正面中景，目视镜头，头肩完整，嘴部无遮挡、自然闭合，给裁切与字幕留空间，不添加文字、水印或拼贴。图生视频的比例跟随参考图，先按横屏或竖屏用途选择图片比例。

在生图指令中加入：**将最终图片保存到当前工作区的 `video/koubo/avatars/`，使用新的 PNG、JPEG 或 WebP 文件名，不覆盖已有图片，并告知保存路径。** 保存后刷新“口播工作室 → 形象”会登记本机图片引用，切换工作区仍可收藏和选用。“使用该形象制作”带入的是原图片的完整路径，工程和成片留在当前工作区；不要覆盖、移动或删除被引用的图片。

先生成一个代表性片段，检查人物、声音和口型后继续。参考图直接使用本地文件，不需要其他服务的 material ID。
